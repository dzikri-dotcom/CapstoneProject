# Presensi Logistik — Frontend (React + Vite)

Antarmuka web untuk admin dan student staff. Panduan lengkap ada di [README utama](../README.md).

```bash
npm install && cp .env.example .env
npm run dev        # http://localhost:5173
npm run dev:lan    # HTTPS + akses dari HP di jaringan yang sama
npm run lint && npm run build
```
